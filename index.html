QueryScope

Everyone reads a query top to bottom: SELECT first. No engine runs it that way. QueryScope rebuilds a query's logical execution order, explains each step in plain English, flags the expensive patterns, and animates the whole thing. Pick an example and press play.

What it catches

  • DISTINCT aggregates — COUNT(DISTINCT x) forces its own distinct pass over the grouped rows.
  • Function-wrapped filter columns — WHERE YEAR(created_at) = 2026 defeats index range scans.
  • Wildcard selects, condition-less joins, sorts with no LIMIT, filters that arrive after the joins.
  • Window functions and scalar subqueries, including the ones hiding inside CTEs.
Run it yourself: python -m queryscope your_query.sql — any dialect sqlglot speaks (Snowflake, BigQuery, DuckDB, Postgres, Spark, and more).
